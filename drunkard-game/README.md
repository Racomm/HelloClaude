# 醉翁觅酒

一个原生 JavaScript 编写的轻度休闲小游戏。玩家控制醉翁移动和跳跃，收集金币与道具，凑够每一关目标金额后购买对应的酒。

## 目录说明

- `drunkard.html`: 游戏入口
- `css/`: 样式文件
- `js/`: 游戏逻辑
- `icons/`: 图标资源
- `drunkard.webmanifest`: PWA 清单
- `GAME_DESIGN.md`: 玩法与关卡设计

## 本地运行

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000/drunkard-game/drunkard.html`。
